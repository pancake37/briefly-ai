# 🚀 Briefly AI

**Briefly AI** — это современное, легкое и автономное веб-приложение для мгновенного получения краткого тезисного изложения (саммари) длинных текстов, статей и документов с умной фильтрацией буфера обмена.

Приложение полностью работает на стороне клиента (SPA) и не требует сервера для запуска — достаточно просто открыть файл `index.html` в любом современном браузере.

---

## 🌟 Ключевые возможности

1. ⚡ **Умный ИИ-Суммаризатор**:
   - Прямая интеграция с **OpenRouter API** для использования лучших языковых моделей (включая бесплатные и премиум модели вроде Gemini, Claude, Llama и др.).
   - Гибкие настройки системного промпта для адаптации вывода под ваши предпочтения.

2. ✨ **Умный буфер обмена (Smart Clipboard Cleaner)**:
   - При вставке (paste) текста приложение автоматически обнаруживает и удаляет рекламный мусор, ссылки на источник ("читать далее...", "источник:") и копирайты популярных веб-ресурсов, оставляя только чистый полезный контент.

3. 🔖 **Библиотека закладок (Bookmarks)**:
   - Встроенная система закладок в стиле Twitter/X, позволяющая сохранять сгенерированные сводки во встроенной библиотеке в `localStorage` вашего браузера.

4. 📂 **Drag & Drop Импорт**:
   - Перетаскивайте текстовые файлы документов размером до 10 МБ прямо на область ввода для моментальной загрузки.

5. 💎 **Премиальный UI/UX**:
   - Изящный минималистичный дизайн с поддержкой адаптивной верстки.
   - Анимированные скелетоны-загрузчики, плавные микроанимации и система всплывающих тостов (Toast Alerts).

---

## 🛠️ Быстрый запуск

Приложение является **полностью автономным (Single Page Application)**:
1. Скачайте или скопируйте папку репозитория.
2. Дважды кликните по файлу `index.html` на вашем ПК.
3. В правом верхнем углу нажмите кнопку **API Ключ**, укажите ваш ключ от **OpenRouter** (начинается с `sk-or-...`) и сохраните его.
4. Вставьте любой текст или перетащите файл — и пользуйтесь!

---

## 🔒 Безопасность и Приватность

- **100% Client-Side**: Все запросы к API и обработка текста происходят исключительно в вашем браузере. Данные не передаются на сторонние промежуточные серверы.
- **Безопасное хранение API-ключа**: Ваш OpenRouter API-ключ хранится локально в `localStorage` вашего браузера и никогда не передается никому, кроме официального эндпоинта OpenRouter API.
